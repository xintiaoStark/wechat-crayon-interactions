SVG 只操作片段内部的图形。点击揭晓让盖住答案的图层消失，原来占的空间保留；真正增高必须改变外层画布高度，并用后面的普通段落核对排版。不要用透明度代替禁用热区；隐藏的组不能拦截当前组的点击。不同样张或多次复制的事件 ID 不得冲突。本生成器采用字母数字 ID 并同步更新 SMIL 事件引用。
